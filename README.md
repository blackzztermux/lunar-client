🌙 Lunar Client

A lightweight local client for remote desktop access and performance monitoring.

Features

- 🌌 Modern dark interface with purple accents
- 🖥️ Remote desktop integration
- 📊 Local CPU, RAM, storage, and network monitoring
- ⚙️ Python backend with Flask
- 📱 Mobile-friendly interface
- 🔧 Configurable remote environment URL

Requirements

- Python 3
- pip
- Termux (Android) or another compatible Python environment

Installation

Clone the repository:

git clone https://github.com/blackzztermux/lunar-client.git
cd lunar-client

Install dependencies:

pip install -r requirements.txt

Start Lunar Client:

python run.py

Open this address in your browser:

"http://127.0.0.1:3000"

Important

Lunar Client is under development. Remote desktop access requires a compatible remote desktop service. Performance metrics initially describe the device running the local backend, not the remote Windows computer.
